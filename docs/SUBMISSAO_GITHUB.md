# Checklist para envio ao GitHub

## O que este repositorio ja cobre

- README com descricao do projeto, stack e instrucoes de execucao
- documentacao de setup local
- diagrama de arquitetura em `docs/ARQUITETURA.md`
- projeto funcional com banco, rotas, painel admin e modulos principais
- script principal do banco versionado em `database/schema.sql`
- registro explicito de uso de tecnologia de IA como apoio ao desenvolvimento

## O que a equipe ainda precisa fazer antes do envio

1. Criar ou ajustar o repositorio publico no GitHub.
2. Conferir se o `.env` local nao sera commitado.
3. Subir o codigo com historico de commits dos integrantes.
4. Validar se o `README.md` representa exatamente a versao enviada.
5. Testar a execucao seguindo apenas o README.
6. Enviar o link oficial pelo formulario do evento.

## Arquivos mais importantes para a banca

- `README.md`
- `docs/ARQUITETURA.md`
- `docs/SETUP.md`
- `database/schema.sql`

## Observacoes

- o item de contribuicao individual depende do historico real de commits no GitHub e nao pode ser fabricado localmente
- se a equipe for de Ensino Superior, manter o link do diagrama de arquitetura visivel no README
- a descricao de uso de IA deve ser mantida como apoio tecnico e de produtividade, sem apagar a responsabilidade da equipe sobre produto, validacao e entrega
